# Roadmap and open ideas

Good places to start. Open an issue to claim one.

- **Upcoming view**: everything with a future When day, by day (Things' Upcoming).
- **This Evening / Someday**: the rest of Things' When values.
- **Repeating to-dos**: "every Monday".
- **Checklist inside a to-do** (Things style), besides nested rows.
- **iPhone app** using the same backend and `Core`.
- **Notarized builds** so people can download the app without Xcode.
- **Deploy to Cloudflare button** + a one-command installer.
- **Webhooks** (HMAC-signed) so an agent hears about changes without polling `get_changes`.
- **Quick Entry** window (Things' Ctrl-Space) that captures into Inbox without opening the panel.
- **Agent rules**: per-list permissions, a cap on unseen agent items.
- **Search across everything** with Cmd-K.
